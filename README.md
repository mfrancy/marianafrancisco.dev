# Mariana Francisco

Portfolio desenvolvido para apresentar minha trajetória, experiência e projetos como Desenvolvedora Front-End.

**Live:** https://marianafrancisco.dev

---

## Sobre

Este projeto foi criado com foco em performance, tipografia e uma experiência visual inspirada em editoriais digitais.

Além de reunir meus principais projetos, o portfólio reflete minha forma de construir interfaces: limpas, funcionais e orientadas à experiência do usuário.

---

## Tecnologias

- Angular
- TypeScript
- SCSS
- HTML5
- CSS3

---

## Funcionalidades

- Design totalmente responsivo
- Navegação por seções
- Animações sutis
- Projetos em destaque
- Timeline de experiência
- Links para GitHub e LinkedIn

---

## Executando localmente

```bash
git clone https://github.com/mfrancy/marianafrancisco.dev.git

cd marianafrancisco.dev

npm install

ng serve
```

A aplicação estará disponível em:

```
http://localhost:4200
```
